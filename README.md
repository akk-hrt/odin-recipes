# Akk-hrt's Odin Recipes

A responsive recipe website created as part of [The Odin Project's Recipes assignment](https://www.theodinproject.com/lessons/foundations-recipes).

## About This Project

This project began as a basic recipe website for The Odin Project Foundations course. The original assignment focused on practising HTML by creating an index page, linking to multiple recipe pages, and organising recipe content with headings, images, paragraphs, and lists.

After completing the original assignment, I extended the project with CSS to improve the layout, visual design, responsiveness, and accessibility.

## Features

- Multi-page recipe website
- Home page with recipe cards
- Individual pages for each recipe
- Navigation between pages
- Responsive layout for different screen sizes
- Recipe images, descriptions, ingredients, and cooking steps
- Semantic HTML structure
- CSS Flexbox layout
- CSS media queries
- Improved visibility of keyboard focus indicators
- Component library page for reviewing reusable design elements

- HTML5
- CSS3

## Design and Accessibility Improvements

In addition to completing the original assignment, I made several improvements to the website:

- Added responsive styles for different viewport sizes
- Created recipe cards with a flexible layout
- Added visual styling for the header and footer
- Improved the readability of recipe content
- Added more visible `:focus-visible` styles for keyboard users
- Used semantic HTML elements such as `header`, `nav`, `main`, `section`, and `footer`
- Added alternative text to images where appropriate
- Organised shared styles in a separate CSS file
